# УДАЛЕННЫЙ ОПЕРАТОР МАША: исходная версия продукта

Этот репозиторий пока является минимально измененным форком RustDesk для проверки
пользовательского сценария удаленной помощи. Функциональный код RustDesk на этом
этапе не изменяется.

## Зафиксированная основа

- Проект: `rustdesk/rustdesk`
- Версия: `1.4.9`
- Commit: `6c578292e8ebbbec708b76986ba8c4bc7c509747`
- Лицензия: AGPL-3.0
- Рабочая ветка: `udu/1.4.9`

Для локальной проверки использован официальный Windows x64 артефакт:

- Файл: `rustdesk-1.4.9-x86_64.exe`
- SHA-256: `EAEDEB0088E687BF46F7C46A9C6EA5493CE51F3134DFD6ACBEDB47B5B9136274`
- Authenticode: действительная подпись `PURSLANE`, Sectigo Public Code Signing CA EV R36

Загруженные исполняемые файлы не добавляются в Git. Сборки форка в дальнейшем
должны публиковаться как отдельные артефакты с исходным кодом соответствующей
версии согласно AGPL-3.0.

## Что уже проверено

Официальный Windows x64 клиент успешно запускается на текущей машине, распаковывает
рабочую копию в `%LOCALAPPDATA%\rustdesk`, создает главное окно `RustDesk` и остается
в отвечающем состоянии.

Это подтверждает запуск приложения, но не подтверждает прохождение удаленной
сессии. Для следующей проверки нужны две независимые Windows-машины или Windows VM.

## Критерий успешного baseline-теста

1. На обоих компьютерах запускается версия 1.4.9.
2. Удаленная сторона сообщает ID и одноразовый пароль.
3. Оператор подключается без регистрации и изменения настроек роутера.
4. Удаленная сторона явно подтверждает подключение.
5. Оператор видит экран и управляет мышью и клавиатурой.
6. Проверяются ввод русского и английского текста, сочетания клавиш и масштабирование.
7. После завершения сессии повторное подключение со старым одноразовым паролем невозможно.
8. Записываются время до подключения, тип соединения (прямое или relay) и причина ошибки.

Baseline-тест завершил этап выбора основы. В ветке `udu/1.4.9` начат первый
брендированный MVP для Windows и Android. Оплата, учетные записи и собственная
серверная логика в него пока не входят.

## Персонализированный MVP

- Название: `УДАЛЕННЫЙ ОПЕРАТОР МАША`.
- Android application ID: `ru.masha.remoteoperator`.
- Android URI scheme: `masha-remote`.
- Windows executable: `masha-remote-operator.exe`.
- Большой логотип используется внутри приложения, компактный - для системных иконок.
- Графические ресурсы генерируются командой
	`python res/generate_udu_brand_assets.py`.
- В разделе «О программе» сохранены ссылка на исходный код, лицензия AGPL-3.0 и
	указание на RustDesk как основу.
- Модель распространения первой версии: условно бесплатное использование
	физическими лицами; платёжный модуль отсутствует.

## Сборка

Официальная x64-сборка 1.4.9 использует Rust 1.75, Flutter 3.24.5, кастомный Flutter
engine RustDesk и vcpkg baseline `120deac3062162151622ca4860575a33844ba10b`.
Эталонный процесс находится в `.github/workflows/flutter-build.yml`, а ручной запуск
полной проверки - в `.github/workflows/flutter-ci.yml`.

На текущей машине локальная полная сборка не запускается из-за ограниченного
свободного места: vcpkg, FFmpeg и промежуточные файлы могут превысить доступные
19.5 ГБ. Предпочтительный путь первой собственной сборки - GitHub Actions.
