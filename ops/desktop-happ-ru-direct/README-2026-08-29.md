# HAPP Sweden: прямой доступ к доменам .ru на desktop

Дата: 29.08.2026.
Устройство: `desktop`.
HAPP: 2.7.0.529.

## Итог

В HAPP импортирован, выбран и включён профиль `RU TLD direct`.
Основное правило: `DirectSites = ["geosite:tld-ru"]`.
Остальной интернет продолжает идти через VPN, так как `GlobalProxy = true`.

## Проверка

- Активный профиль в реестре: `selectedRoutingRule = RU TLD direct`.
- `useRouting = true`.
- HAPP после переподключения сохранил шведский внешний IP `185.189.46.14` для обычного трафика.
- Запрос к `shina-moskva.ru` создал соединение Xray прямо с адресом сайта `77.222.56.183`.
- Контрольный запрос к домену не `.ru` использовал VPN-сервер `88.216.130.158:19813`.

## Примечание

Список `tld-ru` включает все домены `*.ru`; вместе с ними напрямую могут идти и некоторые другие российские доменные зоны из этого же набора.

Резервная копия исходных настроек на desktop:
`C:\ProgramData\Happ\backup-before-all-ru-direct-20260829_143828`.
