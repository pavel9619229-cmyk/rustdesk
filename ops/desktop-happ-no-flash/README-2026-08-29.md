# Desktop: устранение мигающего PowerShell

Дата: 29.08.2026.
Устройство: `desktop`.

## Причина

Задача `Happ Yandex Direct` имела минутный триггер и действие
`powershell.exe -File C:\ProgramData\Happ\ensure-yandex-direct.ps1`.
Монитор процессов подтвердил новый `powershell.exe` и `conhost.exe`
на каждом минутном запуске.

## Исправление

Скрипт переведён в резидентный режим: один скрытый PowerShell-процесс
выполняет основной скрипт каждые 60 секунд. Параметр задачи
`MultipleInstances=IgnoreNew` не допускает ежеминутного запуска новых окон.
Используется mutex `Local\HappYandexDirectResident`.
